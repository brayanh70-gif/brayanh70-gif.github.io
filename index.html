AI_MEDIA_CORP

AI_MEDIA_CORP is a small independent studio that makes original animated short videos about science, history, nature and true survival stories for the YouTube channel Wh4tTheClip.

About the AI_MEDIA_CORP app

The AI_MEDIA_CORP app is a private production tool used only by the channel's owner. It runs on the owner's own computer and uses the YouTube API Services to:

  • upload finished videos, with their title, description and thumbnail, to the owner's own YouTube channel;
  • read the channel's own statistics and analytics so the team can see what works;
  • look up public video statistics to research topics.

It is not offered to the public and does not access anyone else's account.
